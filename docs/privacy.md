# Cyphra privacy model

Cyphra 0.7.3 uses Gecko from SHA-256-pinned LibreWolf 158.0.1-2 archives. Native engine flags disable telemetry, data reporting, crash reporting, Normandy and the upstream updater; the content sandbox stays enabled. Cyphra locks related preferences off and blocks known ingestion endpoints before per-site exceptions. Endpoint lists cannot identify every website tracker. No Chromium or Electron runtime is included.

Trusted local browser chrome loads from a private resource namespace. Only the script-free start page, CSS and logo are content-accessible. The page uses restrictive CSP and Brave Search; it exposes no privileged browser operation to websites. Application-folder write access remains powerful and should be protected as for any desktop software.

Local EasyList/EasyPrivacy data, matcher bundle and compiled snapshot must match their SHA-256 manifest. Cosmetics use validated, bounded class/ID tokens and safe hiding selectors; no scriptlets, remote CSS or page-text transfer. Unassociated browser HTTP housekeeping is cancelled. Exceptions permit the selected DoH endpoint, authenticated sync API, actual website principals and exact in-flight manual news or enabled update requests. Corrupt filters or certificate-revocation data keep the startup gate closed.

Shields counts actual Cyphra request cancellations. Details contain bounded per-tab hostnames/reasons, without paths, query strings, bodies or URL history. Normal attributable totals persist; private totals/exceptions clear after the final private window closes. Counters exclude native Gecko protections and do not estimate unique trackers or bandwidth. Standard, Strict and Off control Cyphra filtering; known telemetry remains blocked under Off.

Work and Personal have separate cookies, logins, bookmarks and settings. Work defaults to Strict filtering, Resist Fingerprinting and disabled WebGL. Personal defaults to Standard filtering and WebGL with native fingerprint protection and cookie partitioning. Saved explicit choices remain in each profile. Neither is a guarantee of perfect security. History defaults off, but bookmarks, downloads, accounts and persistent containers retain ordinary local metadata. Extensions can create their own traffic. DRM is disabled.

DNS is selectable in both editions. Team defaults to Toxitech; Public defaults to System. Encrypted choices use strict TRR-only mode 3 with no silent fallback; System explicitly uses mode 5. The diagnostic queries the selected resolver. Settings change only browser preferences, never OS network configuration. Endpoint hostname bootstrap may use OS resolution; Gecko has special handling for local/reserved names. Resolver operators can observe queries.

HTTPS-only public browsing and native certificate checks remain active; local HTTP labs are supported. A release-bundled Mozilla OneCRL snapshot has verified provenance, SHA-256 integrity and a detached P-384 signature checked against a production-qualified pinned signing key before native certificate-storage installation. Every identity in the authenticated published collection is enforced, matching Gecko; the signed `enabled` metadata field does not remove revocations. This is a dated offline snapshot, not continuous revocation coverage. No full phishing/malware URL database or continuously refreshed CRLite is currently provided. Engine, filters and security data require timely releases. Historical signatures remain verifiable after signer-certificate expiry.

Optional news is manually refreshed and locally cached, without remote images/scripts/fonts. Optional GitHub checking defaults off and never installs silently. Team updates require locally stored credentials; Public updates use its separate public repository/key without a token. Signed version/name/size/hash metadata authenticates online packages. The Windows installer has no Authenticode signature. Offline package file manifests detect corruption, not an untrusted sender.

Manual sync encrypts selected data before uploading opaque ciphertext. New vaults authenticate edition/mode binding; cross-mode/edition pairing is refused. Legacy unscoped vaults remain usable only in Team Work. Passwords, cookies, history, tabs, DNS, update credentials, telemetry and mode fingerprint/WebGL defaults are excluded. Keep pairing codes secret. Public has no default team sync endpoint. GitHub, Brave, DNS operators and news publishers see the service requests you choose to make.

Qualification must cover native Windows installation/runtime/uninstall, longer network observation, real compatibility and independent review. Local automated tests are evidence for tested behavior, not certification. See the release validation report for platform, duration and limitations.
