# Changelog

## 0.7.0 — 10 October 2026

First separate public edition, based on the Cyphra Gecko implementation.

- Personal and Work run in separate profiles, with balanced and stronger defaults.
- Selectable System, Quad9, Cloudflare, Toxitech and custom HTTPS DNS; real resolver diagnostics.
- Quieter monochrome UI, profile switcher, Focus view, tab search and clearer real Shields details.
- Manual encrypted sync binds new vaults to the edition and mode.
- Separate anonymous GitHub updates, public release signing key and installation location.
- Verified Gecko 157.0.1 engine and authenticated offline Mozilla OneCRL snapshot.
- Preserved native browser tools, Brave-only search, local filtering and optional manual security news.
